PC・GitHubまわり 28語

GitHubギットハブプログラムの中身を置いて公開・共有する場所。AI系のツールはだいたいここで配られてる。
Gitギットファイルの変更履歴を記録していく仕組み。それをネット上に置けるようにしたサービスがGitHub。
リポジトリ
別名: レポジトリ
GitHub上の「1プロジェクト分の入れ物」。フォルダみたいなもん。公開(public)と非公開(private)を選べる。
クローン
別名: clone
GitHubにある入れ物を、自分のパソコンに丸ごとコピーしてくること。
フォーク
別名: fork
他人のリポジトリを自分の側にコピーして、好きにいじれるようにすること。
コミット
別名: commit
変更をひとかたまりにして記録すること。ゲームのセーブポイントみたいなもん。
プッシュ
別名: push
手元で直したものをGitHub側に反映すること。逆に取ってくるのが「プル」。
ブランチ
別名: branch
本線を壊さずに作業するための枝分かれ。試してよかったら本線に合流させる。
プルリクエスト
別名: プルリク / pull request
「この変更を取り込んでほしい」という申請。GitHubでは「PR」と略される（広告のPR表記とは無関係）。
READMEリードミーリポジトリの説明書。開いたとき最初に表示されるファイル。
GitHub Pagesギットハブページズリポジトリに置いたHTMLを、そのまま無料でWebサイトとして公開できるGitHubの機能。
デプロイ作ったものを、実際に動く場所に置いて公開すること。
静的サイト置いてあるHTMLを返すだけのサイト。裏で計算せんぶん、無料で公開しやすい。
ターミナル
別名: コマンドライン / CLI / コマンドプロンプト
黒い画面に文字で命令するやつ。Claude Codeもここで動く。
ローカル自分のパソコンの中、という意味。反対が「サーバー上」「本番」。
Node.jsノードジェイエス
別名: npm
JavaScriptをパソコン上で動かすための土台。`npm` はそこに部品を入れるコマンド。
PythonパイソンAI界隈で一番よく使われてるプログラミング言語。
JSONジェイソン設定やデータを書くための形式。`{ }` と `" "` で囲まれてるあれ。
Markdownマークダウン
別名: マークダウン / md
`#` や `-` で見出し・箇条書きを書く記法。AIとのやり取りはだいたいこの形。
HTMLエイチティーエムエルWebページの中身を書く言語。見た目を決めるのがCSS、動きを付けるのがJavaScript。
JavaScriptジャバスクリプト
別名: JS
Webページに動きを付ける言語。ブラウザの中で動く。
ブックマークレットお気に入りに登録しておいて、押すとそのページで動く小さいプログラム。この用語メモがまさにそれ。
拡張機能
別名: エクステンション
ブラウザに後付けする小さいアプリ。
キャッシュ一度読んだデータの一時保存。直したのに画面が変わらんときは、だいたいこれが残ってる。
環境変数APIキーみたいな秘密の値を、ファイルに書かずパソコン側に覚えさせておく置き場。
パス自動検出なしファイルの住所。`C:\Users\...` みたいなやつ。
オープンソース
別名: OSS
中身が公開されてて、誰でも見られる・使えるソフト。
ライセンスそのソフトや素材を、どこまで使ってええかの取り決め。商用利用の可否はここに書いてある。
「自動検出なし」の語は、ふつうの日本語すぎて誤検出するのでページ検出の対象外にしてます（一覧には出ます）。
